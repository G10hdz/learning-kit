%
%  COMO USAR:
%   1. Copia este archivo como AAAA-MM-DD-categoria.tex
%   2. Rellena los campos marcados con <<...>>
%   3. Compila:  pdflatex archivo.tex  (dos veces)
%
%  ESTRUCTURA FIJA:
%   1. Panorama del dia   -> contexto + caja "Mapa mental"
%   2. Resumenes por fuente -> 3-4 temas, cada uno con sourcecard
%   3. Cuaderno de ejercicios -> \exercise / \question + solucionario
%   4. Fuentes y citas    -> referencias con DOI/arXiv
%
%  LONGITUD: flexible, 2-4 paginas. NO forzar \newpage ni relleno.
%
%  ENTORNOS DISPONIBLES:
%   \begin{sourcecard}{Autores (anio)}{Titulo, venue/arXiv.}  ... \end{sourcecard}
%   \begin{concept}{Titulo de la caja}  ... \end{concept}
%   \begin{code}[Lenguaje o etiqueta]   ... \end{code}
%   \begin{solutions}{Solucionario}      ... \end{solutions}
%   \begin{intuition}{Titulo}            ... \end{intuition}   (metaforas, "por que importa")
%   \partdivider{PARTE I \textbullet\ Fundamentos}{Una linea}   (briefs de dos niveles)
%   \exercise Texto del ejercicio (numera solo)
%   \question Pregunta de razonamiento (con vineta)
%
%  PAQUETES: solo TeX Live base. NO usa babel-spanish, newtx,
%  sourcesanspro ni fontawesome (pueden no estar instalados).
%  Escribe el cuerpo SIN acentos o con \'a si hace falta, para
%  maxima portabilidad entre distribuciones.
% ============================================================
